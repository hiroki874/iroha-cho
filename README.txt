いろは帳 1.1.0（Web公開準備版）

【この版で追加したもの】
・アプリ名「いろは帳」
・タスク／日別予定／月別予定の追加・編集画面に、最大3件の日時指定通知
・全体設定に毎日最大3回の定時通知
・PWAマニフェストとService Worker
・通知サーバー（Web Push）用のコード
・タスク、予定、メモ本体は従来どおり各端末のlocalStorageに保存
・通知本文は端末内のAES-GCM鍵で暗号化して通知サーバーへ送信

【まずPCで確認】
1. ZIPを展開し、techo-app フォルダをVS Codeで開く
2. ターミナルで npm.cmd install
3. npm.cmd run dev
4. 表示された localhost のURLを開く

【通知について】
通知の画面・設定と配信サーバーのコードを含みますが、画面を閉じた状態で通知を届けるには、公開サーバーへのデプロイとVAPIDキー設定が必要です。ローカル開発中は通知サーバーがまだ動いていないため、「通知を有効にする」は成功しません。

iPhoneでは、公開後にSafariでサイトを開き「ホーム画面に追加」してから、そのホーム画面アイコンで起動し、通知を許可してください。iOSのWeb Pushはホーム画面に追加したWebアプリで利用します。対応状況は実機で確認してください。

【公開時の構成】
・Webアプリと通知サーバーを同じNode.jsサービスで配信
・Render等の常時稼働できるNode.jsホスティングを利用
・永続ディスクを /var/data にマウントし、DATA_DIR=/var/data を設定
・環境変数 VAPID_PUBLIC_KEY / VAPID_PRIVATE_KEY / VAPID_SUBJECT を設定
・ビルドコマンド: npm install && npm run build
・起動コマンド: npm start

【VAPIDキー】
公開前に、PCのプロジェクトフォルダで次を実行するとキーを生成できます。
npx web-push generate-vapid-keys
表示されたPublic KeyとPrivate Keyを、ホスティング側の環境変数に登録します。Private Keyは公開・共有しないでください。VAPID_SUBJECTは mailto: から始まる連絡先形式にします。

【データとプライバシー】
タスク・予定・メモの一覧は通知サーバーへ送りません。通知サーバーにはPush購読情報、配信時刻、暗号化済み通知本文が保存されます。暗号鍵は各端末のIndexedDBに保存します。端末のブラウザデータを消すと、アプリのデータと通知の復号鍵も消えるため、復旧できません。

【制限・注意】
・定時通知は、アプリを開いた時点の情報をその後90日分の通知として暗号化登録します。アプリを開いて内容を変更したら、次回起動時に予定を更新します。
・Web PushはOS・ブラウザ・通知許可・省電力設定・ネットワーク状況に左右され、必ず指定秒に届く保証はありません。
・この版は公開準備版です。公開前にPCとiPhoneで追加・編集・削除・通知をテストしてください。
